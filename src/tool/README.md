# Project Tools and Developer Utilities

This directory is designated for project tools, helper scripts, and configuration references.

## Key Project Tools
- **Vite**: Frontend bundler and build tool (configured in root `vite.config.ts`).
- **ESBuild**: Backend compiler and bundler (compiles `src/backend/server.js` to `dist/server.cjs`).
- **NPM**: Package manager for dependency and script lifecycle management.
- **Tailwind CSS**: Modern CSS utility framework for professional styling.
